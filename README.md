## درباره کتاب

این کتاب با تکیه بر سال‌ها تجربه تدریس و با بهره‌گیری از تعامل با هوش مصنوعی، مهارت‌های دیجیتال را در شش حوزه اصلی دنبال می‌کند:

1. مبانی رایانه و اینترنت
2. کار با اسناد
3. صفحه‌گسترده
4. ارائه
5. هوش مصنوعی
6. امنیت سایبری

هدف این مجموعه، فراتر رفتن از آموزش ابزارها و کمک به یادگیرندگان برای به‌کارگیری عملی مهارت‌ها در تحصیل، کار و زندگی روزمره است. کتاب با زبانی روشن و رویکردی کاربردی، مفاهیم پایه رایانه را با قابلیت‌های نوین هوش مصنوعی پیوند می‌دهد و بر درک مفاهیم، تمرین، ارزیابی انتقادی و استفاده مسئولانه از فناوری تأکید می‌کند.
